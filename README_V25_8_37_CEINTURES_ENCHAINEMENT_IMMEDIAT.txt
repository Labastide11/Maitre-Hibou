Maître Hibou V25.8.37 — Ceintures : enchaînement immédiat

Règle appliquée aux ceintures Français et Maths :
- dès que l'élève sélectionne une réponse, elle est enregistrée ;
- la question suivante s'affiche immédiatement, sans écran ni délai intermédiaire ;
- aucun surlignage bonne/mauvaise réponse pendant la ceinture ;
- aucune correction intermédiaire ;
- la correction des erreurs reste uniquement à la fin ;
- le verrou anti-double clic / double réponse est conservé.

Les entraînements ne sont pas modifiés : ils peuvent conserver leur feedback pédagogique.
Le raccordement LSU de V25.8.36 est conservé.
