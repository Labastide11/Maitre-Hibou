# Maître Hibou V25.8.50 — afficher la compétence du dernier calcul mental

L'onglet Calcul mental affichait le dernier score, le meilleur score et le meilleur temps,
mais pas le contenu travaillé.

V25.8.50 conserve le libellé du dernier événement `calcul_mental` et affiche sous les quatre
indicateurs :

- « 🎯 Dernière compétence travaillée »
- le libellé de l'entraînement ;
- le score ;
- le temps ;
- la ceinture lorsqu'elle est disponible.

Exemple :
« Trouver un complément à 10 ou 100 — 9/10 · 26 s »

Aucun changement de l'API, du journal élève ou du moteur d'apprentissage.
