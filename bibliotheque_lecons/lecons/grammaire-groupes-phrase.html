Les groupes dans la phrase

Je sais repérer le groupe sujet, le groupe verbal et un groupe que l’on peut souvent déplacer ou supprimer.

1Je retiens
Dans une phrase simple, on peut repérer plusieurs groupes.
Le groupe sujet indique qui ou quoi fait l’action. Le groupe verbal contient le verbe et ce qui est lié au verbe. Certains groupes donnent une précision de lieu, de temps ou de manière : on peut souvent les déplacer ou les supprimer.
2Exemple
Le petit chat mange ses croquettes dans la cuisine.
Groupe sujet · Groupe verbal · Groupe qui précise le lieu
Dans la cuisine, le petit chat mange ses croquettes.
On peut déplacer dans la cuisine sans changer le sens principal de la phrase.
3🦉 L’astuce de Maître Hibou
Cherche d’abord le verbe, puis demande-toi qui est-ce qui ? pour trouver le sujet. Ensuite, teste les autres groupes : peux-tu les déplacer ou les supprimer ? Si oui, ils donnent souvent une précision sur les circonstances.
